# Bundled Roboto font provenance

Source: https://github.com/google/fonts/tree/main/ofl/roboto
Downloaded 2026-10-04. Original normal and italic variable TTFs; no subsetting or font modifications.
Served as WOFF2 since 2026-10-31: each TTF below was converted once, losslessly, with
`uvx --from "fonttools[woff]==4.60.1" fonttools ttLib.woff2 compress -o <name>.woff2 <name>.ttf`.
Every supported browser reads WOFF2, so no TTF fallback is shipped.
