# Verify project productivity

Use isolated state and real user outcomes. Ordinary progress should reuse one URL, update one project file, preserve feedback/history/ownership, and produce no round or agent wake-up. Identical progress is a no-op. Claude Code and Codex successors discover the same page; an owner claim does not build another page.

The regression suite covers CLI discovery/publication, progress writes, submitted-round delivery, reviewer identity, and browser decision editing, text, tabs, themes, and mobile controls. Validate public routing through the real Funnel edge without Tailnet identity before rollout. Check that an outside reviewer can read, explain a changed decision, finish review, and revisit without losing identity or history.

`python scripts/bench.py --help` describes the optional existing review benchmark. Fixtures under `fixtures/` are test data, not authoring instructions. Its explicit review-round scenarios do not measure everyday project productivity. Paid provider comparisons or recurring reports are optional and require their own task; do not run them during ordinary project work.
