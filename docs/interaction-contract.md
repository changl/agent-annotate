# Interaction contract

Use one page per project. Post into Review, Library, Findings, or Plans; keep supporting resources in Documents and previous versions/rounds in History. Share the full canonical Funnel URL. Legacy pages without category data retain Review and their declared tabs.

Each decision supports a choice, Answer in words, an explanation, and a card comment. The shared Send submits pending answers, Library edits, and finding reopens as one durable round before notifying the current owner. Draft clicks do not trigger independent sends. Agents read submitted feedback once, then act; they never confirm for Chang.

Library revisions preserve current text and immutable history. Findings may be marked fixed only with proof; Chang can reopen with an explanation while retaining earlier fix records. Plans have their own revisions and inline comments, without replacing the Review document.

A second page requires --exception "REASON", explicitly requested by the orchestrator. The recorded exception appears under Linked pages. --standalone remains an alias with reason standalone; exception pages keep separate ownership.
