# Full suite on M1Max16: activation on 2026-11-04 (agent-annotate-va0)

Every open PR head from this repository now gets the full suite on **M1Max16** within a minute of its GitHub check passing. The result is a `full-suite` commit status on that exact SHA, linking to the Windmill run. If M1Max16 provably did not start, the same SHA runs on this M1 instead. **No model is called and no tokens are used.** A full run on M1Max16 takes about 11 minutes; the same suite took 26 minutes on the busy M1 today.

## What runs where

- **Windmill (Docker on this M1)**: schedule `f/test/poll_schedule` runs `f/test/poll` every minute. It admits one new trusted head per minute (same-repo branch, owner/member/collaborator), keeps one heavy run per Mac, cancels runs whose head was replaced, and posts the status. `f/test/run` dispatches to the target Mac through Orca after checking the exact Orca runtime ID; nothing launches if that check fails.
- **M1Max16** (primary): the fixed executor, private config, a source cache cloned from the public repo, a Playwright 1.61.0 browser cache, and a minimal PATH (uv, Node 24, Python 3.12, system tools). No Windmill worker or daemon.
- **M1** (backup): the same executor bytes, its own source cache and Playwright cache.
- A failing run's status names up to three failing tests ("Tests failed: a, b" or "5 tests, first: a, b, c"); the linked run has the full IDs. That text is written by `f/test/poll` and the wm-test client, which live in `windmill-build/f/test/` and `skills-org/bin/wm-test`, not in this repository.
- Failover happens only on positive proof that nothing started on M1Max16: the Orca preflight failed, or admission was refused. Test failures, cleanup doubt or lost contact never move a run.

## Credentials

All credentials the pipeline uses are in Infisical (`/projects/agentannotate`, env `dev`) and read at run time by machine identity `wm-test-pipeline`. It is read-only and limited to that folder, and its access tokens last one day. Its client secret, the only bootstrap credential, is a Windmill secret variable plus a login-keychain item on each Mac. The old secret files are deleted.

## Repository change

`scripts/bench.py` produced `(deny process-exec )` with an empty filter when none of tailscale, orca, cloudflared or annotate was on PATH, which blocks every program. M1Max16's minimal PATH exposed it. A regression test fails without the fix and passes with it.
