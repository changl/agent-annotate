## What changed for agents

- `new`, `publish`, `publish-version`, `ask`, `resolve` and `claim` print one line: `v2 live · 3 cards #1–#3`, `resolved #1–#3 in v2`, `claimed NAME`. `--verbose` prints the old line with the page link; `--json` is unchanged.
- `inbox` prints one line per answer or note, led by its number, then `resolve when done: annotate resolve PAGE 1 2 3`. Publishing, delivery and status events are hidden (`--all-events` shows them); the undecided list is a count. `--verbose` prints the old table.
- `resolve PAGE 1 2 3` closes several items in one call. Every number is checked first; one unknown number resolves nothing. `#1` and bare `1` both work; the old one-item form still runs.
- The skill is shorter and loads the page reference only for other blocks or a refused card.

Not done here: `--worklist FILE` and `resolve --from FILE` (the inbox's resolve line covers the round); one server transaction for a batch resolve (items are checked first, then written one by one; a failure names the items already resolved); mail-type wake breakdown in the meter.
