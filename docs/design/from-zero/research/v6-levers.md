## Method and limits

Keep the first study’s piece/pass links, unit boundaries and check labels unchanged. Each unit has four written verdicts, reasons and evidence links in `DATA/v3/passes2/labels-final.jsonl`; mixed notes remain whole. Strict condition needs a specific earlier correction covering the same approval. Strict direction needs a real pass-one alternative using information known then, never a later-discovered technical result. Strict direct means one adjustable value/order. Strict authority needs the dated earlier grant and all its limits. Plausible departures state the missing evidence.

For every subset, a pass disappears only when every original unit delegates, moves to pass one, folds into an explicitly linked earlier pass, or is caught by the frozen checks. Conditional acceptance travels to the latest earlier note completing its specification, following that note if direction moves it; even a checked-away note needs a pass to carry this acceptance. Thus a correction and its later approval cannot both vanish. Newly inspected states keep their approvals. Per-pass ledgers preserve every unit and movement; the work table contains all 32 combinations. All effects assume successful repair, useful controls and an early sample that elicits the recorded preference.

A seeded random fifth of this exact denominator was recoded with first labels/comparisons hidden: **45/46 exact eight-bit agreement (97.8%)**, or **13/14** among units positive in either reading. Strict direction agreed on 45/46; the other seven lever/bound readings each agreed on 46/46. Seed: 20261112. This is the same researcher, not an independent rater; negative rows and remembered judgements can inflate agreement. This checks labels, not claimed savings. Afterward two linked mixed reload/colour units were conservatively downgraded; one rollout approval became strict after full option comparison confirmed identical deployment consequences. The first reading remains frozen.

No prospective checker/control/sample experiment, actual control use, owner-time measurement, full historical pixel inspection or device run was performed. Earlier asks, authority and final acceptance are incomplete in places; missing evidence is upper-only. No other Mac or live product was operated. Source wording, existing choices and before/now locators support this coding, but do not prove that an earlier sample would have elicited every later preference. No production change or commit was made.
